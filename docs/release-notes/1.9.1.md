## Wisp 1.9.1

**Better at "what's this?"**

- Wisp now notes where your pointer is when you **let go** of the shortcut (and what's under it), so you can
  move onto the thing while you're asking.
- Fixed: the pointer's position was given to the default AI model in the wrong units, so questions like
  "what does this do?" could look in the wrong place. It now uses the same units the model answers in.

Requires macOS 15 or later on a Mac with Apple silicon.
