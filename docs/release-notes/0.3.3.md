## Wisp 0.3.3

Better answers, using the app you're in:

- New optional setting **Better answers**. With the Accessibility permission, Wisp reads the names of the
  buttons, switches and menu commands of the app in front (never what you type) when you ask a question.
  It then knows which buttons are greyed out, which switches are already on, and each menu command's
  keyboard shortcut.
- The cursor now lands exactly on the button it names, even if the picture was hard to read.
- When the answer is a menu command ("File > Duplicate"), Wisp tells you the menu and shortcut instead of
  pointing at something unrelated.
- Turn it on in Settings > Permissions or Settings > Privacy. Wisp works without it as before.

In our test on 58 questions over 7 real Mac apps, correct answers went from 69% to 85%, and every point landed
on the right place.

Requires macOS 15 or later on a Mac with Apple silicon.
