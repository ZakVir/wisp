## Wisp 2.0.0

**Quick actions.** Double-tap Control (or choose Type a Question…): under the box, Wisp now suggests what it can
do, and narrows them down as you type. Press ↓ / ↑ to choose and Return to run, or click one:

- Summarize this page · Read this page aloud · Read the selected text aloud
- Copy the text on screen · Keyboard shortcuts in the app you're using
- Set a timer… · Remind me… (fills in the start; finish typing and press Return)
- Translate this page… · Make the selected text more polite · Fix the grammar
- History · Check Wisp · Pause Wisp for 1 hour · What's New

Typing a question and pressing Return still asks it, as before.

Requires macOS 15 or later on a Mac with Apple silicon.
