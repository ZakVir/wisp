## Wisp 1.4.0

**Claude, for teams.** Settings > AI > Provider now includes **Anthropic (Claude)**, for organizations with their
own Anthropic account:

- Models: **Claude Sonnet 5.5** (recommended), **Claude Haiku 4.5** (fastest) and **Claude Opus 5.5** (most
  capable).
- Paste the organization's Anthropic API key (stored encrypted on this Mac, like the NVIDIA key); **Test
  Connection** and **Check Wisp** work with it.
- Everything else (pointing, Better answers, guidance, private apps) works the same. Companies can set and lock
  the provider and model with a settings file (see 1.3.0).

The free NVIDIA option stays the default.

Requires macOS 15 or later on a Mac with Apple silicon.
