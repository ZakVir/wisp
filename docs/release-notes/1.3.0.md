## Wisp 1.3.0

**Settings files.** Set up several Macs the same way: Settings > General > **Export Settings…** saves this
Mac's Wisp settings (voice, shortcut, About you, private apps, caption size and so on) to a file; on the other
Mac, **Import Settings…** applies it.

- AI keys are never in the file: add the key on each Mac (or use your company's own AI service).
- For IT: the same file can be installed as Wisp's managed settings
  (`/Library/Application Support/Wisp/managed-config.json`) to set those settings for everyone and lock them.

Requires macOS 15 or later on a Mac with Apple silicon.
