## Wisp 2.8.0

**Light computer use.** Wisp can now do small things for you, and you watch the cursor do each step, with the
action happening exactly as the cursor clicks:

- **Open apps:** "open Chess", "open Notes", "switch to Mail". If the app is in the Dock, the cursor clicks it
  there; if not, Wisp opens the Apps launcher, types the app's name and presses Return.
- **One thing in an app:** "open Notes and make a new note", "open TextEdit and start a new document", "open a
  new tab". Wisp picks the one menu command that does it (the free AI helps when the wording differs) and clicks
  the menu, then the command.
- **Search on a site:** "open up my browser and open Instagram and search for improving Claude Code setup",
  "search YouTube for lofi music", "look up running shoes on Amazon". Wisp opens a new tab, types the site in the
  address bar, then clicks the site's search box, types your search and presses Return.
- **Web searches and sites** as in 2.7.0 ("search the web for …", "open YouTube"), now typed for real.

How it stays light and safe:
- At most **one** small step inside an app per request; bigger jobs ("…and start making a 3D model") get an
  offer to walk you through instead.
- It never chooses commands that delete, send, buy, sign out, quit or reset.
- Keys go only to the app being used, and only while it's in front.
- Real clicking and typing needs **Better answers** (Settings > Permissions). Without it, Wisp still opens apps
  and pages directly, with the cursor showing where.
- Turn it all off in Settings > General > Let Wisp open apps and websites for you.

Requires macOS 15 or later on a Mac with Apple silicon.
